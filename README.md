# Retail Sales Performance Dashboard (Excel + Power BI)

## 📌 Project Overview
This project focuses on transforming raw transactional retail data into actionable business insights. It demonstrates core skills in **Data Preprocessing using Python**, data formatting, and building an interactive dashboard for sales performance tracking.

---

## 🛠️ Tech Stack & Skills Demonstrated
- **Data Wrangling:** Python (Pandas)
- **Data Management:** Advanced Excel (Pivot Tables, Functions)
- **Data Visualization:** Power BI (KPI Cards, Region-wise Charts)
- **Business Insights:** Profit Margin Analysis, Sales Growth Tracking

---

## 📁 Repository Structure
- 📄 `README.md`: Project documentation.
- 🐍 `data_cleaning.py`: Python script used to clean missing values and calculate metrics.
- 📊 `cleaned_retail_sales.csv`: Cleaned dataset used as the data source for the dashboard.
